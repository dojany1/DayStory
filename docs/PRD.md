# PRD: DayStory

## 목표

매일 한 장의 역사 카드와 내가 쓴 일기 카드를 같은 디자인 언어로 모아 보여주는 모바일 한국어 앱을 만든다. 사용자는 가볍게 콘텐츠를 소비하고, 자연스럽게 자기 하루도 기록하게 된다.

## 사용자

- 매일 짧은 인문학/역사 콘텐츠를 소비하고 싶은 한국어 사용자 (20~30대).
- 일기는 쓰고 싶지만 빈 페이지 앞에서 막막해하는 사람 — "오늘 어떤 역사가 있었지?" 라는 카드가 글감을 던져준다.
- 로그인 없이도 콘텐츠를 즉시 보고 싶은 게스트 사용자.

## 핵심 기능

1. **편지 (오늘의 역사 카드)** — 그날의 역사 카드 한 장을 펼쳐 보여준다. 좌우 스와이프로 인접한 날짜로 이동, 휠 피커로 임의 날짜 점프, 카드 탭으로 앞/뒷면 플립. 뒷면 버튼으로 에디터의 한마디를 본다.
2. **캘린더** — 한 달 달력 위에 카드 미리보기. "역사 일화 / 나의 일화" 토글로 두 모드를 전환한다. 빈 날짜를 누르면 그 날 일기 쓰기로 진입한다 ("이 날 한 줄 써볼까?" 유도).
3. **내 일기** — 편지와 동일한 카드 + 휠 피커 UI 위에 내 글을 얹는다. 빈 날짜에는 강조된 [나의 일화 쓰기] 버튼. 사진은 4:5 크롭 + 회전 후 자동 업로드.
4. **북마크** — 별표 친 역사 카드를 격자로 모아본다. 인물·국가·요약 검색. 게스트는 localStorage, 로그인 사용자는 Firestore에 저장.
5. **내정보** — 프로필(닉네임/사진 1:1 크롭), 라이트/다크/시스템 테마, 글꼴 크기, 위젯 테마, 튜토리얼 다시 보기, 로그아웃, 회원 탈퇴.

부가:

- **에디터 한마디 (✍️)** — 카드 뒷면에서 에디터 사진/이름/한마디를 말풍선으로. 처음 본 카드에는 빨간 ! 표시.
- **튜토리얼 다시 보기** — 내정보에서 시작하면 각 화면의 주요 영역을 포커싱하고, 사용자가 [다음]을 누를 때만 페이지별 안내가 한 단계씩 진행된다. 카드, 캘린더, 내 일기, 북마크, 알림, 위젯 설정을 포함한다.
- **안드로이드 위젯** — 홈 화면에 오늘의 카드 미리보기 + 내 일기 바로가기.
- **에디터 권한** — 지정된 관리자 이메일 3개에만 콘텐츠 관리 메뉴 노출.

## MVP 제외 사항

- 소셜 피드 / 팔로우 / 좋아요 / 댓글
- 다국어(영어 등) — 한국어 전용
- 푸시 광고, 구독/결제
- 다른 사용자의 일기 공개 열람
- 웹 데스크톱 전용 UX (모바일 폭 430px 고정)

## 디자인

- **테마**: 라이트 / 다크 / 시스템(OS 따라감) 3가지. 모든 화면은 두 테마에서 동일하게 동작.
- **컬러 팔레트**: 무채색 + 시맨틱(성공 #34c759, 경고 #ff9f0a, 오류 #ff3b30, 정보 #14ade5). 강조색은 라이트에서 검정, 다크에서 흰색 — 브랜드는 "글자와 카드"로 만든다 (네온/그라데이션/유리 효과 금지).
- **포맷**: 카드 1장이 모든 화면의 중심. 아래 5탭이 항상 같은 자리.
- **타이포**: `LINESeedKR` (한글), `Inter` (영문). 본문 가독성 우선.
- **모션**: GSAP 카드 플립과 페이지 페이드인만 허용. 펄스/글로우/패럴랙스 금지.

## 데이터 (참고)

- 역사 카드: Firestore `stories`
- 내 일기: Firestore `mystories`
- 프로필: Firestore `profiles/{uid}`
- 북마크(로그인): Firestore `bookmarks`, (게스트): localStorage
- 사진 파일: Firebase Storage `users/{uid}/...`

## Known Limitations

- **`/editor` 라우터 가드** — 관리자 권한 검사가 페이지 렌더 시점에서만 일어나며 `router.beforeNavigate` 단계에 강제되지 않는다. Firestore 보안 규칙으로 서버 측 보호 필요.
- **페이지 cleanup** — 13개 페이지 중 일부만 `setOnUnmount`로 리스너를 정리한다. SPA 메모리 누수 가능성. 자세한 목록은 [\_archive/CODE_MAP.md](./_archive/CODE_MAP.md) "Known Issues" 참조 (※ v1.4.0 Wave 4 에서 `setOnUnmount` 실 구현 완료, 일부 이슈는 해소됨).
