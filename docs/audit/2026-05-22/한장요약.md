## 🔴 지금 당장 손봐야 하는 것 5개

1. **결제 안내가 거짓말 중** — 후원 버튼 누르면 "결제 완료!" 메시지는 뜨는데 실제로는 돈이 안 빠짐. 누가 신고하면 스토어에서 앱 내려갈 수 있음. [donate.js:88](../../../src/js/pages/donate.js#L88)
   - **할 일**: 그 안내 문구만 일단 빼거나, 페이지를 숨겨라.

2. **누구나 자기를 "관리자"로 만들 수 있을 가능성** — 코드에서 특정 이메일이면 `role='editor'`로 자기 데이터에 저장함. 파이어베이스 보안 규칙이 막지 않으면 누구든 코드 만져서 권한 탈취 가능. [login.js:83](../../../src/js/pages/login.js#L83)
   - **할 일**: 파이어베이스 콘솔 들어가서 `firestore.rules` 가 일반 유저의 role 변경을 막는지 확인.

3. **로그인하면 게스트 시절 북마크 다 날아감** — 로그인 안 한 상태로 북마크 모았다가 로그인하면 합쳐주는 코드가 없음. "북마크 다 사라졌다" 별 1점 리뷰의 단골 원인. [bookmarks.js:76](../../../src/js/services/bookmarks.js#L76)
   - **할 일**: 로그인 시 게스트 북마크를 서버로 옮기는 로직 추가, 아니면 최소한 "로그인하면 게스트 데이터 사라져요" 경고라도.

4. **저장 버튼 두 번 누르면 일기 두 개 생김** — 네트워크 끊겼다가 다시 누르면 중복 저장됨. [mystories.js:48](../../../src/js/services/mystories.js#L48)
   - **할 일**: 저장 중에는 버튼 잠그기.

5. **브라우저 `confirm()` 팝업 남아 있음** — 에디터 빠져나갈 때 "정말 나가시겠습니까?" 가 시스템 팝업으로 뜨는데 모바일 웹뷰에서 가끔 앱 꼬임. 자체 모달(`confirmDialog`)이 이미 있는데 한 곳만 안 바뀜. [editor.js:413](../../../src/js/pages/editor.js#L413)
   - **할 일**: `confirmDialog` 로 교체 (5분 작업).

## 🟠 다음 패치(1.4.x) 때 챙길 것

1. **돈 받을 준비를 켜라** — 구독 라이브러리(RevenueCat)가 깔려만 있고 켜지지 않음. 그냥 깔린 채로 놔두면 평생 수익 0원. 지금이 켜기 가장 좋은 타이밍.

2. **화면 떠날 때 청소 안 함** — SPA라 화면 바꿔도 이전 화면이 등록한 이벤트 리스너가 계속 살아있음. CLAUDE.md 규칙엔 "라우터에 청소 함수 등록해라" 라고 적혀 있는데 **그 함수가 실제로는 코드에 없음**. 지금 당장 안 터지지만 카드 화면 → 일기 화면 왔다갔다 많이 하면 점점 느려짐. [router.js:211](../../../src/js/router.js#L211)

3. **수집(컬렉션) 기록이 휴대폰 안에만 있음** — 폰 바꾸거나 앱 지우면 모았던 카드 다 날아감. 사용자가 모은 만큼 앱에 묶이는 게 핵심인데 그 묶임이 약함. 서버에 저장하도록 바꾸기.

4. **검색이 데이터 늘면 터짐** — 모든 카드를 다 받아와서 폰에서 거르는 방식. 카드 1000장 넘어가면 모바일 메모리 부족으로 끊김. [stories.js:232](../../../src/js/services/stories.js#L232)

5. **모든 유저가 켤 때마다 같은 일을 함** — 예약된 카드 발행 처리를 모든 사용자 앱이 동시에 시도함. 사용자 100명 동시 접속 = 똑같은 작업 100번. 서버 단에서 한 번만 하도록 옮기기. [stories.js:96](../../../src/js/services/stories.js#L96)

6. **빠진 디자인 변수들** — CSS에서 `--font-sans`, `--text-md` 같은 변수를 쓰는데 정의된 적이 없음. 지금은 브라우저가 알아서 무시하지만 폰트가 의도와 다르게 나옴.

7. **애니메이션 끌 수 없음** — 멀미 잘 나는 사용자나 접근성 옵션 켠 사람한테 카드 플립 애니메이션이 그대로 작동. 한 줄 CSS(`@media (prefers-reduced-motion: reduce)`) 추가하면 됨. 접근성 심사 통과에도 유리.

## 🟡 천천히 해도 되는 것 (요약)

- **페이지 정리**: `donate`/`report`/`license`/`about` 4개 페이지가 거의 빈 페이지. 설정 화면 안에 섹션으로 흡수해서 페이지 수 줄이기.
- **카카오톡 공유 SDK** 붙이기 — 한국 앱인데 카톡으로 공유 안 되면 입소문이 안 남.
- **알림 기본값 켜기 + 첫 진입 때 안내** — 지금은 알림이 기본 꺼짐 + 설정 깊숙히 있어서 사용자 99%가 못 켬. 알림이 재진입의 유일한 트리거인데 차단되어 있음.
- **중복 코드 정리**: 같은 함수(`withTimeout`, Firebase URL 판별, HTML 이스케이프)가 서로 다른 파일에 3~4번 복붙되어 있음. 한 곳으로 모으기.
- **report 페이지의 신고 데이터가 어디에도 저장 안 됨** — 사용자는 신고했다고 믿는데 어디로도 안 감.
