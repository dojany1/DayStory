## 🔴 긴급 P0 — 더미 데이터 노출 (2026-05-24 처리)

- **증상**: 관리자(`role='editor'`) 계정은 정상이지만, **일반 사용자 계정에는 5개의 데모 카드(리처드 1세 · 에펠탑 · 반 고흐 · 콜로세움 · 뉴턴)** 가 그대로 노출됨.
- **원인**: Wave 4에서 도입한 [firestore.rules](../../../firestore.rules) 가 일반 사용자에게 `status == 'published'` 문서만 read 허용함. 그런데 [src/js/services/stories.js](../../../src/js/services/stories.js) 의 쿼리에는 `status` 필터가 없어, DB에 `draft/scheduled` 문서가 하나라도 있으면 권한 거부로 전체 쿼리 실패 → catch 블록이 `DEMO_STORIES` 반환. 관리자는 `isAdmin()` 가드 통과로 모든 문서 read 가능해 폴백이 트리거되지 않아 비대칭이 발생.
- **조치**:
  - `stories.js` 의 5개 함수(`fetchStories`, `fetchTodayStory`, `fetchStoryById`, `searchStoriesDB`, `fetchStoriesWithLicense`) 에서 데모 폴백 완전 제거. 빈 결과/오류는 `[]` 또는 `null` 반환.
  - 컬렉션 쿼리에 `where('status','==','published')` 추가 (Firestore 보안 룰과 일치).
  - `src/js/data/demo.js` 파일과 폴더 삭제.
  - `editorstory.js` · `search.js` 에 빈 상태 메시지 추가 (`detail.js` · `license.js` 의 빈 케이스는 기존 UI 재사용).
  - `tests/stories-fallback.spec.js` 신규 — 권한 거부 / 빈 응답 / 정상 응답 3개 시나리오 × 5개 함수 회귀 가드.

## 사용자 결정 6개 (이번 패치에 포함)

1. **튜토리얼 잔재 정리** — 이미 거의 다 빠져있고, 문서/주석에서만 정리 
2. **결제(donate) 페이지 제거** — 페이지·라우터·메뉴만. RevenueCat 의존성 자체는 안 건드림
3. **게스트 모드 완전 제거** — 앱 켜면 무조건 로그인 화면. 기존 게스트 데이터는 자연 소멸
4. **알림 기본값 ON** — 새로 가입하면 일기 알림이 켜져 있는 상태
5. **카카오톡 공유 SDK 추가** — 한국 사람들 공유는 결국 카톡
6. **Firebase 보안 룰 코드화** — 레포에 `firestore.rules`/`storage.rules` 만들어서 관리. 배포는 따로 명령어 실행

> 코치마크는 후보였으나 사용자가 명시적으로 제외함.

audit에서 시급(🔴)으로 잡혔던 것들 중 위 결정만으로 해결되는 것:

- ✅ "RevenueCat 깔려는 있고 안 켜져 있다" → 켤 필요 없음. 깔린 채로 둠

**할 일**:

- 에디터에서 빠져나갈 때 뜨는 시스템 confirm 팝업 → 자체 모달(`confirmDialog`)로 교체 ([editor.js:413](../../../src/js/pages/editor.js#L413))

**왜**: 가장 위험 적은 작업부터. 다음 단계 들어가기 전 빌드 깨지는지 확인용.

### 2단계 — 게스트 모드 완전 제거 (반나절~하루, 가장 큰 작업)

**할 일**:

- `src/main.js`에서 로그인 안 했으면 무조건 `/login`으로 보냄
- 코드 전체에서 `'guest'` 분기 찾아서 다 삭제 (30곳 정도, services 3개·pages 5개·main·components 1개)
- `bookmarks.js`의 localStorage 게스트 분기 7곳 → Firestore 단일 경로만 남김
- `images.js` 의 `uid='guest'` 기본값 → uid 필수 인자로
- `report.js`도 함께 제거 (저장 안 되는 placeholder니까)
- 로그인 페이지에서 "게스트로 둘러보기" 같은 CTA가 있으면 제거

**왜**: 가장 큰 작업이지만 한 번에 해야 깔끔. 중간에 멈추면 게스트/로그인 모드가 어중간하게 섞임.

**테스트 추가**: 비로그인 상태에서 `/calendar`/`/mystory`/`/bookmarks` 접근 시 `/login`으로 강제 이동. 기존 14개 테스트 회귀 없음.

**수동 확인**: 새 브라우저에서 앱 열어보고, 모든 경로가 로그인으로 막히는지.

---

### 3단계 — 디자인 토큰 + 접근성 (반나절)

**할 일**:

- CSS 변수에 빠진 토큰 4개 추가 (`--font-sans`, `--text-md`, `--color-text-on-image`, `--color-editor-comment`)
- 폰트 크기 토글이 안 먹는 곳들 정리 (px 하드코딩 → rem 또는 토큰)
- 글로벌 `@media (prefers-reduced-motion: reduce)` 추가 → 멀미 안 나도록 애니메이션 다 꺼주기 (+ 해당 부분은 잘 이해 안 됨, 추가 설명 필요)
- 뒤로가기 버튼·캘린더 화살표 터치 영역 36→44px로 키움 (+ 버튼 터치 영역을 늘리는 것은 좋으나, 이로 인해 해당 컨테이너 자체가 커지지는 않았으면 좋겠어.)
- 하드코딩된 색깔들 토큰으로 교체 (`#3f3200`, `#1c1c1e`, `#34c759`)
- z-index magic number(`100000`, `9999`, `10000`) 토큰화

**왜**: 출시는 됐지만 접근성 점수 떨어지고, OS 글꼴 크게 쓰는 사용자한테 깨짐. 애플 심사·Play 정책에서 트집 잡힐 수도.

**수동 확인**: 라이트/다크 토글, 폰트 작게/크게/보통 전환, OS 접근성에서 "동작 줄이기" 켜고 카드 플립.

### 4단계 — 안정성 핵심 (반나절~하루)

**할 일**:

- `router.setOnUnmount(fn)` 함수 실제 구현 → CLAUDE.md 규칙은 있는데 코드에 없던 함수. 페이지 떠날 때 청소 등록 가능하게.
- 글로벌 `window._editorStoryMouseMove` 패턴 ([editorstory.js:634](../../../src/js/pages/editorstory.js#L634), [mystory.js:712](../../../src/js/pages/mystory.js#L712)) → `setOnUnmount` 로 정리
- `fetchMyStories` uid가 비어있으면 빈 배열 ([mystories.js:11](../../../src/js/services/mystories.js#L11))
- 일기 저장 버튼 잠금 (네트워크 끊김 + 재탭 시 중복 저장 방지)
- 북마크 버튼 빠른 더블탭 잠금
- Storage URL 식별을 문자열 검색 → URL 호스트 파싱으로 ([stories.js:323](../../../src/js/services/stories.js#L323))
- **Firebase 보안 룰 파일 신설**: `firestore.rules`, `storage.rules`, `firebase.json` 등록
  - 핵심: 누구도 자기 `role`을 `editor`로 못 바꾸게 차단
  - Storage 업로드는 본인 폴더만 + 파일 크기 10MB + image/\* MIME만
- `sanitizeUrl` 화이트리스트(`http(s)`/`mailto`/`tel`)로 강화

**왜**: 메모리 누수 근본 원인 해결 + audit P0 보안 위험 차단.

**수동 확인**: 페이지 왔다갔다 30번 정도 한 다음 Chrome DevTools에서 메모리 안 새는지. 사용자가 별도로 `firebase deploy --only firestore:rules,storage` 실행.
